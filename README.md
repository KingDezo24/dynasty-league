# Dynasty League app

The league's home-screen app: standings, power rankings, playoff odds, matchups, trades, picks, records, rule changes and the Clubhouse.

Open https://kingdezo24.github.io/dynasty-league/ on your phone, then add it to your home screen
(iPhone: Safari → Share → Add to Home Screen. Android: Chrome menu → Install app).

All league data comes live from the league's Google Apps Script. Nothing private is stored in this repository.
